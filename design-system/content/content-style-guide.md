# Digital AI — Content Style Guide

## Voice & Tone

### Arquétipo: Sábio + Herói

**Sábio**: clareza, precisão, conhecimento que transforma.
**Herói**: resultado concreto, ação, supera obstáculos.

### Voz da Marca

- **Inteligente, não hermética** — conhecimento acessível
- **Próxima, não informal demais** — respeito com calor
- **Confiável, não corporativa** — consistência sem burocracia
- **Direta, não agressiva** — clareza sem imposição

### Tom por Contexto

| Contexto | Tom | Exemplo |
|---------|-----|---------|
| Onboarding | Acolhedor + orientador | "Vamos configurar seu espaço juntos." |
| Erro | Empático + solucionador | "Algo deu errado. Aqui está o que fazer:" |
| Sucesso | Celebratório + reforçador | "Pronto! Sua automação está rodando." |
| CTA | Confiante + acionável | "Ver resultados" não "Clique aqui" |
| Vazio | Encorajador + orientador | "Nenhuma automação ainda. Crie a primeira." |
| Técnico | Preciso + contextualizado | "webhook.digital-ai.tech recebeu 0 requisições nas últimas 24h." |

## Microcopy

### Labels de Formulário
- Sempre substantivos, não verbos: "Nome" não "Digite seu nome"
- Sem pontuação no final do label
- Placeholders como exemplos: "ex: João Silva" não "Insira aqui"

### Mensagens de Erro
- Diga O QUE aconteceu + O QUE fazer
- "Email inválido — use o formato nome@empresa.com"
- Nunca: "Erro 400" ou "Campo obrigatório" sem contexto

### Botões
- Verbos de ação: "Salvar", "Criar automação", "Ver relatório"
- Evitar: "OK", "Submit", "Confirmar" sem contexto
- Destrutivos devem deixar claro: "Excluir permanentemente"

### Empty States
1. **Ilustração ou ícone** contextual
2. **Título**: o que não existe ainda (não "Nada aqui")
3. **Subtítulo**: por que isso importa
4. **CTA**: ação para resolver o estado vazio

## Terminologia

| Use | Não use |
|-----|---------|
| Automação | Bot (depreciativo) |
| Agente de IA | Robô, chatbot genérico |
| Fluxo | Workflow (se audiência não-técnica) |
| Conectar | Integrar (se audiência não-técnica) |
| Painel | Dashboard (se audiência não-técnica) |
| Pergunta frequente | FAQ |

## Formatação

- **Negrito** para termos-chave e ações críticas
- _Itálico_ apenas para ênfase semântica (raro)
- Listas para 3+ itens paralelos
- Números para sequências ordenadas
- Capitalização: Título Case apenas em headings H1/H2. H3+ em sentence case.

## Internacionalização

- Data: DD/MM/AAAA (Brasil)
- Hora: HH:mm (24h)
- Moeda: R$ 1.234,56
- Decimal: vírgula (1.234,56)
- Milhar: ponto (1.234)
